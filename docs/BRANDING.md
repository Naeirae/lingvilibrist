# Branding and icon deliverables

Lingvilibrist should look like a standalone public product rather than a renamed internal extension.

## Icon set

Required release assets:

- 16x16 PNG — browser toolbar;
- 32x32 PNG — high-density toolbar/menu use;
- 48x48 PNG — extension management UI;
- 128x128 PNG — Chrome extension listing/package;
- one vector/master source kept separately from generated raster sizes.

## Product criteria

The icon should:

- remain recognizable at 16 px;
- avoid small text/letters that collapse at toolbar size;
- use a single clear silhouette;
- visually belong to an editorial/language tool rather than generic AI branding;
- avoid workplace-specific symbols and colors;
- work on both light and dark browser chrome;
- be exported from one master design, not independently redrawn per size.

## Repository presentation assets

Before the first portfolio-ready release, add:

- repository social preview image;
- one clean popup screenshot;
- one review-flow screenshot/GIF;
- architecture diagram;
- example finding card (`before -> after -> why`).

## Status

Icon regeneration is required before the first packaged public extension release. Temporary/internal icons must not be copied into the public release without an explicit branding review.
